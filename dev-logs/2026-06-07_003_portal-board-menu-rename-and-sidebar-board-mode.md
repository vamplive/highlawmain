# 인트라넷 "내부 게시판" 메뉴를 "게시판"으로 변경하고, 게시판 진입 시 사이드바를 게시판 전용 메뉴로 전환

날짜: 2026-06-07
요청자: 운영자
배경: 운영자가 인트라넷(`/portal/*`) 좌측 사이드바의 "내부 게시판" 메뉴명을 "게시판"으로 바꾸고, 게시판 관련 메뉴(게시글 쓰기, 게시판 필터, 전체 게시판 카테고리 트리, 휴지통)는 다른 메뉴에서는 보이지 않다가 "게시판"으로 들어갔을 때만 기존 전체 메뉴를 대체해 나타나도록 요청. 또한 게시판 메뉴에서 상단에 화살표 형태의 뒤로가기 버튼으로 전체 메뉴로 복귀할 수 있게 하고, 전체 메뉴에서는 게시판으로 이동할 수 있는 버튼을 만들며, `/portal/board`에서는 "전체 게시글"·"공지사항" 등 게시판들을 각각 볼 수 있도록 구성해 달라고 요청함.

## 변경 사항

### 1) `frontend/src/pages/portal/PortalLayout.jsx` — 사이드바를 경로 기반으로 "전체 메뉴 / 게시판 메뉴" 두 모드로 분리
- `location.pathname.startsWith("/portal/board")` 여부로 `isBoardMode`를 계산해, 사이드바 메인 영역을 조건부 렌더링하도록 재구성.
  - **전체 메뉴 모드** (게시판 외 모든 경로): 기존 11개 메뉴 링크(일정 캘린더, 사건 목록, 게시판, 타임트래킹, 프로필 설정, 블로그 관리, 법률 Q&A 관리, 전자결재 시스템, AI 연동 설정, 메시지 발송, 홈페이지 바로가기)만 표시. "내부 게시판" 라벨을 "게시판"으로 변경(클릭 시 `/portal/board`로 이동 = 게시판 메뉴로 가는 버튼 역할 겸함).
  - **게시판 메뉴 모드** (`/portal/board*` 경로): 기존 전체 메뉴 대신, 상단에 `ArrowLeft` 아이콘과 "전체 메뉴" 텍스트로 구성된 뒤로가기 버튼(클릭 시 `/portal/calendar`로 이동해 전체 메뉴로 복귀)을 배치하고, 그 아래 "게시판" 헤더 + 게시글 쓰기 버튼 + 게시판 필터(최신글/필독/중요/내 게시글) + 게시판 이름 검색창 + 전체 게시판 카테고리 트리(공지사항/업무 매뉴얼/자유게시판/양식) + 휴지통을 표시.
- 기존 코드의 모든 핸들러·상태(`boardSearch`, `filteredCategories`, `activeCategory`, `activeFilter` 등)와 스타일은 그대로 재사용했고, 두 모드 사이에서 중복되던 요소(게시글 쓰기 버튼, 필터 섹션 등)는 게시판 모드 쪽으로 이동시켰을 뿐 새로 만들지 않음.
- `lucide-react`에서 `ArrowLeft` 아이콘 추가 임포트.

### 2) `frontend/src/pages/portal/PortalBoard.jsx` — 게시판 페이지 내에서 "전체 게시글 / 카테고리별 게시판" 빠른 전환 탭 추가
- 페이지 상단(제목·글쓰기 버튼 영역과 검색바 사이)에 `boardTabs`(전체 게시글/공지사항/업무 매뉴얼/자유게시판/양식) 알약형 탭 바를 추가. 클릭 시 `category` 쿼리 파라미터를 설정/해제하고 `filter`·`search`·페이지를 초기화해 해당 게시판만 조회하도록 `handleSelectBoardTab`을 구현.
- 기존에도 `category` 파라미터가 없으면 "전체 게시글"(모든 카테고리 글 통합 조회)을, 있으면 해당 카테고리만 조회하는 로직(`fetchPosts`, 제목 표시 `getCategoryLabel`)은 이미 구현돼 있었으므로, 탭은 그 기능을 사이드바 트리 없이도 페이지 안에서 바로 전환할 수 있게 해주는 보조 내비게이션으로 추가함.

## 검증 절차
1. `npx eslint src/pages/portal/PortalLayout.jsx` — No issues found.
2. `npx eslint src/pages/portal/PortalBoard.jsx` — 3 errors, 2 warnings 보고되었으나, `git diff -U0`으로 대조한 결과 모두 본 작업 이전부터 존재하던 이슈(미사용 `navigate`/`e` 변수, `useEffect` 의존성 경고)이며 신규 추가 코드(`boardTabs`, `handleSelectBoardTab`, 탭 바 JSX)에는 해당하지 않음을 확인.
3. 브라우저에서 직접 화면 동작을 확인하지 못했으므로(자동화된 브라우저 도구 부재), 운영자가 실제 화면에서 (a) "게시판" 메뉴 클릭 시 사이드바가 게시판 전용 메뉴로 바뀌는지, (b) 뒤로가기 버튼으로 전체 메뉴 복귀가 되는지, (c) `/portal/board`에서 탭으로 전체 게시글·카테고리별 게시판이 잘 전환되는지 1차 확인을 권장.

## 향후 개선
- 현재 뒤로가기 버튼은 `/portal/calendar`(홈)로 이동하는 방식으로 구현됨. 추후 "게시판에 머무르되 사이드바만 전체 메뉴로 보기"가 필요해지면, 경로 기반 판단 대신 별도의 토글 상태를 두는 방식으로 전환 검토 가능.
