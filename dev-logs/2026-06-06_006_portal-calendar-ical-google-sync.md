# 포털 캘린더 구글 연동 iCal 피드 구현 및 안내 모달 추가

날짜: 2026-06-06
요청자: 운영자
배경: 포털 캘린더(/portal/calendar)의 일정을 외부 구글 캘린더와 실시간 동기화하여 구독할 수 있도록 iCal 피드 URL을 제공하고, 사용자 화면에서 이를 손쉽게 연동할 수 있는 팝업 안내 및 주소 복사 기능을 구현합니다.

## 변경 파일
- `backend/routes/portal.js` — /calendar/sync-info (사용자 개별 iCal 구독 링크 생성) 및 /calendar/feed (인증 토큰 검증 후 RFC 5545 iCalendar 포맷의 일정 파일 데이터 제공) 라우트 추가.
- `frontend/src/pages/portal/PortalCalendar.jsx` — 상단 헤더에 "구글 캘린더 연동" 버튼 추가, 클릭 시 고유 피드 URL 복사 및 구글 캘린더 등록 가이드 단계를 보여주는 안내 모달 구현.

## 검증 절차
1. **빌드 검증**:
   - `frontend` 폴더에서 `npm run build`를 완료하여 컴파일 에러가 없음을 확인.
2. **백엔드 테스트 검증**:
   - `backend` 폴더에서 `npm test`를 수행하여 410개 전체 테스트 케이스가 성공적으로 패스됨을 확인.

## 향후 개선
- 구글 캘린더의 크롤러 스케줄러(보통 수 시간 주기) 외에, 수동으로 즉시 동기화가 필요한 경우 캐시 무효화 파라미터 활용 안내 추가 검토.
