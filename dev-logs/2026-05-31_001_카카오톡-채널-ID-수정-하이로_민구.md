# 카카오톡 채널 ID 수정 + 변호사 정렬 순서 변경

날짜: 2026-05-31
요청자: 운영자
배경: 법무법인 하이로 카카오톡 채널의 공식 ID가 highlawofficial로 설정되어, 홈페이지의 카카오톡 연결 버튼이 올바른 채널로 연결되도록 수정 요청

## 변경 파일
- `frontend/src/utils/kakaoChannel.js` — KAKAO_CHANNEL_ID를 `_xfMTxan`에서 `_highlawofficial`로 변경
- `backend/data/db/yjlaw.db` — lawyers 테이블 sort_order 직접 수정 (강민구1→3, 조덕재3→1, 김범2 유지)

## 변경 전/후 변호사 순서
- 변경 전: 강민구(1) → 김범(2) → 조덕재(3)
- 변경 후: 조덕재(1) → 김범(2) → 강민구(3)

## 검증 절차
1. 플로팅 카카오톡 버튼 클릭 → https://pf.kakao.com/_highlawofficial/chat 으로 이동 확인
2. 상담 페이지 카카오톡 문의 버튼 클릭 확인
3. /api/lawyers 응답에서 조덕재→김범→강민구 순으로 반환 확인
4. 변호사 목록 페이지 표시 순서 확인
