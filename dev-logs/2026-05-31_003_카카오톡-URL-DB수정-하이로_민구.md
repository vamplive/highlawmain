# 카카오톡 URL 윤정→하이로 전환 (코드 + DB 3단계 수정)

날짜: 2026-05-31
요청자: 운영자
배경: 카카오톡 버튼을 누르면 구버전 윤정법률사무소 채널(_xfMTxan)로 연결되는 문제.
      kakaoChannel.js는 이미 _highlawofficial로 수정되어 있었으나, 관리자 사이트매니저의
      DEFAULT_SETTINGS(constants.js)와 DB에 구버전 URL이 잔존하여 덮어쓰기가 발생했음.

## 원인 분석
1. useSiteSettings(admin) 훅 초기값: DEFAULT_SETTINGS["layout/contact"].kakaoUrl = "_xfMTxan"
2. 관리자가 이 기본값 그대로 저장 → DB에 구버전 URL 기록
3. FloatingContact는 DB 값 우선 사용 → 코드 상수 변경만으로는 부족했음

## 변경 파일
- `frontend/src/pages/admin/site-manager/constants.js` — DEFAULT_SETTINGS layout/contact: kakaoUrl _xfMTxan → _highlawofficial, telegramUrl YounSeHwan 제거, phone 번호 정정
- `frontend/src/components/layout/layoutConfig.js` — LAYOUT_DEFAULTS.contact: kakaoUrl 빈값→_highlawofficial, kakaoEnabled false→true
- `backend/data/db/yjlaw.db` — site_settings 테이블에 layout/contact 행 신규 삽입 (kakaoUrl: _highlawofficial, kakaoEnabled: true)

## 검증 절차
1. 홈페이지 카카오톡 플로팅 버튼 클릭 → https://pf.kakao.com/_highlawofficial/chat 연결 확인
2. 관리자 사이트매니저 → 레이아웃 탭 → 카카오톡 URL 필드에 올바른 URL 표시 확인
3. 상담 페이지 카카오톡 문의 버튼 확인
