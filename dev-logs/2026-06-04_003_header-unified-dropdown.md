# 헤더 드롭다운의 단일 직사각형 통합 및 구분선 제거

날짜: 2026-06-04
요청자: 운영자
배경: 헤더 드롭다운이 개별 박스 대신 하나의 큰 직사각형 패널로 나타나고, 그 안의 하위 링크들 사이에 불필요한 구분선을 없앰으로써 디자인의 일관성을 높이기 위함. 또한 6개 탭의 간격을 균등하게 맞춤.

## 변경 파일
- `frontend/src/components/layout/Header.jsx`
  - 개별 NavLink 내부에 있던 드롭다운들을 제거하고, 전체 `<nav>`의 하위 형제 요소로 단일 absolute 드롭다운 컨테이너 배치
  - `display: "grid"`, `gridTemplateColumns: "repeat(6, 1fr)"` 속성을 이용하여 6개 컬럼이 동일한 너비와 일관된 간격(`gap: 16`)으로 레이아웃되도록 설정
  - 드롭다운 링크 간의 `borderBottom` 속성을 제거하여 구분선이 노출되지 않도록 함
  - 각 링크의 상하/좌우 패딩을 `6px 8px`로 통일하여 정돈된 레이아웃 제공
  - 단일 absolute 패널에 맞도록 페이드인 애니메이션을 `fadeIn`으로 적용 (기존 `dropdownFadeIn`은 `translateX(-50%)`가 묶여있어 그리드에 부적합함)
