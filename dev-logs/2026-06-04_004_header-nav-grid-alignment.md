# 헤더 메뉴와 드롭다운 컬럼의 그리드 정렬 및 하위 탭 명칭 간략화

날짜: 2026-06-04
요청자: 운영자
배경: 헤더의 메뉴 텍스트와 드롭다운 내부 컬럼들이 수평으로 일치하지 않고 어긋나는 현상을 해결하고, 드롭다운 내의 하위 탭들이 줄바꿈되지 않고 완전히 1줄로 표시되도록 레이아웃 및 명칭을 최적화하기 위함.

## 변경 파일
- `frontend/src/components/layout/layoutConfig.js`
  - 드롭다운의 하위 탭 명칭 중 공백이나 불필요한 단어를 제거하여 간략화 및 단축:
    - "오시는 길" → "오시는길"
    - "변호사 소개" → "변호사소개"
    - "강의 활동" → "강의활동"
    - "상담 필요여부" → "상담대상"
    - "하이로의 강점" → "하이로강점"
    - "업무 분야" → "업무분야"
    - "판례 분석" → "판례분석"
    - "법률 가이드" → "법률가이드"
    - "채용 공고" → "채용공고"
    - "지원 안내" → "지원안내"
    - "채용 문의" → "채용문의"
    - "상담 신청" → "상담신청"
    - "진행 절차" → "진행절차"
- `frontend/src/components/layout/Header.jsx`
  - 상단 주요 메뉴 `<nav>` 요소를 기존 flex 구조에서 드롭다운과 동일한 **`lg:grid grid-cols-6`** 그리드 구조로 전면 개편
  - 메뉴와 드롭다운의 시작 위치 및 컬럼 분할을 완벽하게 맞추기 위해, `<nav>`와 드롭다운 카드에 동일한 가로 패딩(`lg:px-4 xl:px-6`) 및 가로 간격(`lg:gap-3 xl:gap-4`) 클래스 부여
  - 주요 메뉴 링크(`NavLink`)와 드롭다운 서브 링크(`Link`)의 좌측 시작 위치를 일치시키기 위해 `NavLink`에 `paddingLeft: 8`, `paddingRight: 8` 적용
  - 서브 메뉴 탭이 절대 줄바꿈되지 않도록 `whiteSpace: "nowrap"` 속성 명시
