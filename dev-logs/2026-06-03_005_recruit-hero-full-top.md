# 채용 페이지 히어로 이미지 상단 여백 제거

날짜: 2026-06-03
요청자: 운영자
배경: 채용(/recruit) 페이지에서 히어로 이미지가 페이지 맨 위까지 표시되지 않고 하얀 여백이 생기는 문제 수정 요청

## 변경 파일
- `frontend/src/components/Layout.jsx` — `hasDarkHero` 조건에 `/recruit` 경로 추가

## 원인
`Layout.jsx`의 `hasDarkHero` 변수는 헤더를 투명하게 히어로 위에 오버레이할 페이지 목록을 정의한다.
채용 페이지가 이 목록에 없었기 때문에 헤더가 불투명하게 별도 렌더링되어 히어로 위에 흰 공간이 생겼다.

## 검증 절차
- `/recruit` 접속 → 히어로 이미지가 화면 최상단까지 표시됨 확인
- 헤더가 히어로 위에 투명하게 오버레이됨 확인
- 스크롤 시 헤더가 정상적으로 불투명으로 전환됨 확인

## 향후 개선
- 새 페이지 추가 시 `hasDarkHero` 목록 업데이트 누락 방지를 위해 pathname prefix 패턴으로 통합 고려
