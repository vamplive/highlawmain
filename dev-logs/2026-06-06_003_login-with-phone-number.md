# 포털 로그인 시 휴대폰 번호로 로그인 기능 추가

날짜: 2026-06-06
요청자: 운영자
배경: 의뢰인 포털 로그인 시 기존 이메일 방식 외에 회원가입 때 등록한 휴대폰 번호로도 로그인할 수 있도록 보완하여 사용자의 접근 편의성을 향상하고자 함.

## 변경 파일
- `backend/services/portal-service.js`
  - `loginUser` 함수 내부에서 로그인 아이디 입력값 분기 처리.
  - 입력값에 `@`가 포함되어 있으면 기존과 동일하게 이메일로 검색.
  - `@`가 없으면 공백 및 하이픈을 제거한 휴대폰 번호 형식으로 변환한 뒤, `clients` 테이블에서 일치하는 `phone`을 가진 고객 정보를 조회.
  - 일치하는 고객이 있고 해당 고객의 `id`와 연계된 `portalUsers` 레코드가 있으면 해당 계정으로 비밀번호 검증 및 세션 생성 진행.
  - 매칭 실패 시 최종적으로 이메일로 한 번 더 검증하고 오류 메시지를 "이메일/휴대폰 번호 또는 비밀번호가 올바르지 않습니다"로 통합 개선.
- `frontend/src/pages/public/LoginPage.jsx`
  - `LoginForm` 컴포넌트 내의 입력 필드 라벨을 "이메일"에서 "이메일 또는 휴대폰 번호"로 수정.
  - 모바일 번호 등 `@`가 없는 일반 문자열을 입력받아 브라우저 자체 HTML5 이메일 형식 정규식 검증에 걸리지 않도록 `type="email"`에서 `type="text"`로 변경.
  - 플레이스홀더를 "이메일 또는 휴대폰 번호 입력"으로 변경하고 관련 프론트엔드 검증 오류 메시지도 통일.

## 검증 절차
- 프론트엔드 소스 빌드 테스트 (`npm run build`) 완료
