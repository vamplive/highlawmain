# 구성원 페이지 직급 탭 디자인 변경 (타원형/Pill 스타일 및 높이 통일)

날짜: 2026-06-04
요청자: 운영자
배경: `/partners` (구성원) 페이지에 적용되었던 직급 분류 탭의 디자인을 업무분야 등 타 페이지의 탭 디자인과 동일하게 타원형(Pill) 버튼 형태로 개편하고 높이를 통일(minHeight: 44px)하여 사이트의 UI 일관성을 보완하기 위함.

## 변경 파일
- `frontend/src/pages/lawyers/LawyersPage.jsx`
  - 기존 텍스트 및 하단 밑줄 강조 방식의 탭 디자인 제거.
  - 타원형 테두리 및 둥근 모서리(`borderRadius: 24`), 최소 높이(`minHeight: 44`)가 지정된 Pill 버튼 형태로 탭 스타일을 리뉴얼.
  - 활성화 상태(Selected) 탭 버튼은 골드 색상(`var(--accent-gold)`) 배경에 흰색 텍스트로 채우고, 비활성화 탭 버튼은 투명 배경에 연한 그레이 테두리가 나타나도록 통일.
  - 모바일 환경에서의 탭 줄바꿈 및 간격 대응을 위해 `flex-wrap: "wrap"`, `gap: "12px"`, `marginBottom: 40` 등 레이아웃 수치 적용.

## 검증 절차
- 로컬 `npm run build` 성공 확인
- Git push 및 서버 자동 배포를 통한 확인 예정
