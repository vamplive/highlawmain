# 홈페이지 전체 스마트폰 최적화

날짜: 2026-05-31
요청자: 운영자
배경: 공개 페이지 전반의 모바일(스마트폰) 사용성 개선 요청

## 진단 결과
- 전체 85% 모바일 대응 완료 상태
- 핵심 버그: HomeHero CTA 버튼에 flexWrap: nowrap 인라인 스타일이 CSS의 세로 스택 규칙을 덮어씀
- HomePeopleSection 변호사 카드 고정 280px + flexShrink: 0 → 320px 소형 폰 넘침
- FloatingContact iOS 하단 세이프 에어리어 미처리
- home.css / homeTokens RESPONSIVE_STYLES 480px 이하 미흡

## 변경 파일
- `frontend/src/index.css` — html/body overflow-x: hidden, -webkit-tap-highlight-color 추가
- `frontend/src/pages/home/HomeHero.jsx` — CTA 버튼 flexWrap: nowrap 제거, whiteSpace: nowrap 제거, transform 클래스화(hp-hero-content-shifted)
- `frontend/src/pages/home/home.css` — hp-hero-content-shifted 미디어쿼리 추가 (768px: 14vh, 480px: 8vh, 데스크톱: 24vh), hp-hero min-height 580px 모바일 조정, hp-solution-card 패딩 축소
- `frontend/src/pages/home/homeTokens.js` — RESPONSIVE_STYLES: 480px hp-section 패딩 축소, hp-title 폰트 clamp 조정, hp-cta-buttons align-items stretch
- `frontend/src/pages/home/HomePeopleSection.jsx` — LawyerCard width: 280px + flexShrink: 0 → width: min(280px, 100%)
- `frontend/src/components/FloatingContact.jsx` — floating-contact-stack CSS 클래스 도입, safe-area-inset-bottom @supports 처리, 모바일에서 버튼 48px로 축소
- `frontend/src/pages/qna/QnaHubPage.jsx` — 검색 input width: 180 → min(180px, 40vw), 내부 flex div에 flexWrap: wrap 추가

## 검증 절차
1. Chrome DevTools 모바일 시뮬레이터(iPhone SE 375px, Galaxy S8 360px)로 홈, Q&A, 상담 페이지 확인
2. 홈 히어로 CTA 버튼 → 480px 이하에서 세로 스택으로 전환 확인
3. 변호사 카드 → 모바일에서 전체 너비 적용 확인
4. 플로팅 버튼이 iOS 하단 홈 인디케이터에 가리지 않는지 확인
5. Q&A 검색 바 → 소형 폰에서 가로 넘침 없는지 확인

## 향후 개선
- 실제 기기(iOS Safari 17+, Android Chrome) 테스트 권장
- 변호사 상세 페이지(LawyerDetailPage) 탭 오버레이 문제 소폭 개선 여지 있음
