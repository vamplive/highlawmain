# /login 통합 로그인/회원가입 페이지 신설

날짜: 2026-06-01
요청자: 운영자
배경: highlaw.co.kr/login 주소로 직접 접근 가능한 로그인+회원가입 통합 페이지 요청

## 변경 파일

### 프론트엔드 (frontend/frontend/src/)

- `pages/public/LoginPage.jsx` (신규)
  - 관리자 로그인과 동일한 스플릿 스크린 레이아웃
  - 좌측: 히어로 영상 + 그라디언트 오버레이 + HIGHLAW 브랜딩 + 인용구
  - 우측: "로그인" / "회원가입" 탭 전환
  - 로그인 성공 → /portal/dashboard 이동
  - 회원가입 성공 → 승인 대기 안내 화면 (리다이렉트 없이 인라인 표시)
  - 이미 로그인 중이면 /portal/dashboard 자동 이동
  - 히어로 영상: 관리자 설정 영상 연동 (localStorage 캐시 + API)

- `pages/public/LoginPage.css` (신규)
  - 프리미엄 스플릿 스크린 스타일
  - 좌측 배지 pulse 애니메이션, 탭 전환 트랜지션
  - 반응형: 900px 이하에서 좌측 패널 숨김 (모바일)

- `components/layout/Header.jsx`
  - 데스크톱 nav 우측에 "LOGIN" 버튼 추가 (골드 테두리, 홈페이지 테마 반영)

- `components/layout/MobileMenu.jsx`
  - 하단 "포털 로그인" 버튼 추가 (골드 테두리)
  - 기존 "관리자 페이지" 링크 스타일 정리 (회색으로 축소)

- `App.jsx`
  - `/login` 라우트 신규 등록 (Layout 없음, 풀스크린)
  - `/portal/login` → `/login` 리디렉트
  - `/portal/register` → `/login` 리디렉트

- `pages/portal/PortalLayout.jsx`
  - 미인증 리디렉트: `/portal/login` → `/login`
  - 로그아웃 후 리디렉트: `/portal/login` → `/login`

## 검증 절차

1. `highlaw.co.kr/login` 접속 → 스플릿 스크린 로그인 화면 확인
2. 상단 헤더 우측 "LOGIN" 버튼 클릭 → /login 이동
3. 모바일 햄버거 메뉴 → "포털 로그인" 버튼 확인
4. 로그인 탭: 이메일+비밀번호 입력 후 로그인 → /portal/dashboard 이동
5. 회원가입 탭: 폼 작성 → 제출 → 승인 대기 안내 화면 표시
6. 이미 로그인 상태에서 /login 접속 → /portal/dashboard 자동 이동
7. /portal/login → /login 리디렉트 확인
8. 900px 이하 화면 → 좌측 패널 숨김, 우측 폼 전체 화면

## 향후 개선

- 로그인 성공 시 이전 페이지로 돌아가는 기능 (returnTo 파라미터)
- 회원가입 후 관리자 이메일 알림 자동 발송
- 소셜 로그인 (카카오/구글) 연동 옵션
